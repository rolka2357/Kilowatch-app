# Kilowatch Download

Static Vite + React landing page for sharing the Android APK (local first).

## Run locally

```bash
cd kilowatch-download
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## APK template

Put your build at:

`public/apk/kilowatch.apk`

The Download button links to `/apk/kilowatch.apk`.

## Notes

- Sibling of `kilowatch-app` and `kilowatch-admin` (same pattern as admin).
- Light / dark mode (admin colors + Roobert).
- No hosting configured yet — localhost only.
